# Library Management System

A command-line Library Management System built with Python and Object-Oriented Programming (OOP).

## Features

- Add books and register library members.
- View all books and registered members.
- Prevent duplicate book IDs and member IDs.
- Borrow and return books.
- View books borrowed by a specific member.
- Handle invalid menu inputs and common errors.

## Concepts Used

- Classes and objects
- Instance attributes and methods
- Lists and object relationships
- Loops and conditional statements
- `match/case` statements
- Exception handling
- Input validation

## How to Run

1. Install Python 3 if it isn't already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

## Note

This project stores book and member records in memory. The records reset when the program exits.
